# READBLOOM — hoja de ruta de producto

## Base profesional actual

- Identidad visual READBLOOM y logo integrado.
- Dashboard de lectura con acciones rápidas.
- Navegación Material 3 y componentes con estados claros.
- Accesibilidad: controles táctiles amplios, alto contraste y reducción de movimiento.
- Onboarding inicial.
- Biblioteca, progreso, favoritos y sesiones.
- Retos anuales, mensuales y personalizados.
- Estadísticas y calendario de actividad.
- Wrapped y Bookish configurables.
- Personalización global.
- Copia de seguridad/restauración e importación CSV.
- Flujo de CI para APK, AAB y Windows.

## Próximas mejoras recomendadas

1. Base de datos local robusta (SQLite/Drift) para grandes bibliotecas y migraciones.
2. Motor de temas desacoplado para guardar y compartir temas personalizados.
3. Editor visual de Wrapped/Bookish por capas, con posiciones y tamaños libres.
4. Búsqueda avanzada con filtros guardados.
5. Sincronización opcional entre dispositivos.
6. Integraciones oficiales con catálogos/API cuando se decida qué proveedores usar.
7. Sistema de logros y rachas.
8. Widgets de Android.
9. Tests de integración y pruebas de accesibilidad.
10. Publicación progresiva en Google Play mediante pista interna y beta.
